# 算数ワールドパーク GitHub Pages公開版 v30

小学3年算数の20単元を、ブラウザだけで使える静的HTMLの学習アプリです。単元ごとに合計40,000問の問題プールを用意し、1セット10問で出題します。確認用の問題例と、単元別の問題生成ルールを組み合わせています。

## 問題プールと点検

- 合計40,000問。20単元それぞれに標準・活用（うち5,617問はジャンプ相当の応用問題）・CBT型を収録
- 問題文の重複を除外し、4択は選択肢の重複・正解ラベル・正解値の対応を検査
- 単位をまたぐ長さ・重さや、余りのある文章題で、解説が入力する答えまで示すことを点検
- CBTの数値4択は、位のずれや計算ミスを想定した正解に近い誤答を優先。正解と同じ値や重複値がないことを全問点検
- 7,572問の直接計算式と、解説中の29,963か所の計算式を照合
- 40,000問を再生成して点検。学年外用語などの指定語句、選択肢の答え違いの検出は0件
- 点検を再実行する場合は、Node.jsで `node qa-audit.js` を実行
- 問題は未出題を優先し、ひととおり出題した後は再びランダムで挑戦
- 最後に残った1〜9問を出題している間は履歴を保ち、単元の問題を出し切ってから新しい周回へ切り替え
- 周回切り替えを小さな問題プールで再現確認し、セット内の重複がないことを点検
- 20単元すべてで通常セットの「基本6・活用2・CBT型2」、CBTセットの10問選択、未出題優先を点検
- 時刻・わり算・あまりのあるわり算で、CBT型の選択式と自分で入力する形式が両方含まれることを点検
- 学習記録を単元ごとに正しく分け、答え合わせ数と正答率が一致することを点検
- まちがえたときに選択肢の答え、分数、単位つきの答えを正しく表示するか点検
- 数字と「十」の不自然なつながり、学年外の用語、未置換の値も全問チェック
- 三角形の単元を年間指導計画に合わせ、辺の長さによる分類と正三角形のしきつめに整理。単元案内・CBT選択肢も同じ範囲に修正

## 学習機能

- 10問セット、基本・活用・ジャンプ・CBT型を組み合わせた出題、CBT型優先モード
- 数字入力、文字入力、選択式、分数の分子・分母入力と縦表示
- 商とあまり、時刻、km・m、kg・gなど複数の数を答える問題は、欄を分けて入力
- 正解の赤い○・不正解の青い×と短い音。まちがえたときは正しい答えも表示
- 問題ごとの手書き計算スペース、ヒント、途中終了の確認
- 正誤と学習内容ごとの記録、おすすめ問題と苦手単元の復習
- 通常セットは基本6問・活用2問・CBT型2問で、活用のうち1問はジャンプ問題。複数の情報を組み合わせる応用問題に毎回挑戦
- セット結果を基本・活用・CBT型に分けて表示し、単元画面でタイプ別の累積正答率を確認
- ホームの「今日のおすすめ」から、正答率が低い単元または未挑戦・未出題が多い単元へすぐ進める
- 単元マップに答え合わせ済み問題数と正答率を表示。10問で単元クリアにはならず、くり返し取り組める
- 色鉛筆＋水彩画風のホームイラスト

## 記録

出題履歴・正誤記録は利用中のブラウザ内に保存します。正誤記録は単元ごとの圧縮データに分けて保存し、以前の記録形式からも自動移行します。端末やブラウザが変わると共有されず、閲覧データを消去すると記録も消えます。

## 開き方

`index.html` をブラウザで開いてください。`question-banks.js`、`question-engine.js`、`qa-audit.js`、`assets/park-hero.jpg` は同じフォルダー構成のまま置いてください。
